FAQ

Frequently asked questions

Does LipiVoice Pro work completely offline?

An internet connection is needed when downloading an AI model for the first time. After the selected model has downloaded, transcription works offline.

Why does Windows show a SmartScreen warning?

The installer is not digitally code-signed, so Windows may show “Windows protected your PC” or “Unknown publisher.” Select More info and then Run anyway if you downloaded it from the official purchase page.

Does the application require administrator access?

No. The installer is designed for the current Windows user and normally does not require an administrator password.

Which languages are supported?

The underlying transcription models support many languages, including Bengali, English, Hindi, Urdu, Arabic, Spanish, French, German, Chinese, Japanese and Korean.

Can Bengali audio be translated into English?

Yes. Enable the translation option to create English output from supported non-English speech.
